# Cypress Documentation

## Overview

This document outlines the setup and structure of Cypress. This app is using :
* Cypress as main framework

## System Requirements

* Node Js 24.0 or higher

## Installation Steps

* Clone the project and move to project directory

```bash
https://github.com/codenameryuu/mycondo-api-cypress.git
```

* Install dependencies

```bash
yarn
```

* Install Cypress in System

```bash
npx cypress install
```

* Run Application in Development

```bash
yarn start
```
